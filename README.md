# Python ADK Learning Repo

Repo do nauki Pythona ukierunkowanej na Google Agent Development Kit (ADK), zaprojektowane do współpracy z lokalnym agentem AI.

## Główna idea
To nie jest zwykły zbiór notatek.
To AI-native learning repo, w którym:
- plan nauki jest zapisany w plikach,
- kolejne moduły są generowane i rozwijane lokalnie,
- wszystkie materiały są grupowane modułami,
- agent AI pracuje zgodnie z zasadami z `AGENTS.md`.

## Gdzie zacząć
1. Przeczytaj `docs/learning_plan.md`
2. Przeczytaj `AGENTS.md`
3. Wygeneruj albo rozwiń pierwszy moduł w `modules/`

## Struktura
- `docs/` — zasady i plan
- `modules/` — materiały nauki
- `templates/` — szablony modułów
- `shared/` — wspólne notatki i postęp
- `prompts/` — prompty pomocnicze

## Cel końcowy
Po przejściu przez repo użytkownik ma:
- swobodnie pisać Python w praktyce,
- rozumieć kluczowe wzorce potrzebne do pracy z ADK,
- tworzyć własne narzędzia, workflow i agentów.
