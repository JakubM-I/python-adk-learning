# Knowledge Check Review Prompt Compact

Ocen odpowiedz po polsku.

Zasady:
- Sprawdz, czy uczen rzeczywiscie odpowiada na pytanie.
- Nie rob dlugiego wykladu.
- Dla odpowiedzi niepelnej lub ogolnej ustaw `needs_revision`.

Format:
- `summary`: maksymalnie 1 zdanie.
- `comments`: maksymalnie 2 uwagi.
- `next_step`: jedno pytanie lub maly krok.
