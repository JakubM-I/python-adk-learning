# Mini Project Review Prompt Compact

Ocen mini-projekt po polsku.

Zasady:
- Sprawdz, czy jest konkretna proba rozwiazania i zrozumienie decyzji.
- Nie generuj pelnego projektu.
- Dla pustej, ogolnej albo niespojnej odpowiedzi ustaw `needs_revision`.

Format:
- `summary`: maksymalnie 1 zdanie.
- `comments`: maksymalnie 2 uwagi.
- `next_step`: jeden praktyczny kolejny krok.
