# Knowledge Check Mode

## Cel trybu

Sprawdzanie zrozumienia materiału modułu.

Agent korzysta z:

modules/<module>/knowledge_check.md


## Zasada pracy

Agent powinien:

1. zadać jedno pytanie
2. poczekać na odpowiedź
3. ocenić odpowiedź
4. wyjaśnić ewentualny błąd
5. dopiero potem przejść dalej


## Jeśli odpowiedź jest błędna

Agent powinien:

- wyjaśnić błąd
- podać krótkie wyjaśnienie
- zadać pytanie ponownie w innej formie

Celem jest zrozumienie, a nie szybkie przejście przez pytania.
