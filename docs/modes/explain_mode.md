# Explain Mode

## Cel trybu

Wyjaśnianie lub pogłębianie tematów z materiałów modułu.

Agent powinien odnosić się do:

modules/<module>/module.md


## Styl wyjaśnienia

Wyjaśnienia powinny:

- zaczynać się od intuicji
- zawierać przykład kodu
- pokazywać mechanizm działania
- wskazywać typowe pułapki
- porównywać z JavaScript jeśli to pomaga


## Zasada aktywnego uczenia

Wyjaśnienie powinno kończyć się pytaniem sprawdzającym lub krótkim zadaniem.
