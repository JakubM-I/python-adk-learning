# Review Mode

## Cel trybu

Analiza jakości materiałów modułu.


## Co agent powinien sprawdzić

1. czy struktura modułu jest poprawna
2. czy sekcje są wystarczająco rozwinięte
3. czy są przykłady kodu
4. czy pojawiają się typowe pułapki
5. czy materiał odnosi się do ADK
6. czy ćwiczenia są stopniowane


## Wynik review

Agent powinien:

- wskazać problemy
- zaproponować poprawki
- ewentualnie zaproponować rozwinięcie sekcji
