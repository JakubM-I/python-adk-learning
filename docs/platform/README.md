# Platforma lokalna

Ten katalog zawiera instrukcje dla osobnej warstwy projektu: lokalnej aplikacji webowej do przerabiania modułów w przeglądarce.

Materiały edukacyjne nadal powstają w `modules/`.
Platforma ma je czytać, renderować i ułatwiać aktywną naukę, ale nie powinna ich modyfikować podczas zwykłego użycia.

## Dokumenty

- `product_spec.md` — cel produktu, zakres MVP i kolejne etapy.
- `architecture.md` — proponowany stack, granice systemu, API i model danych.
- `content_contract.md` — jak platforma ma interpretować pliki Markdown modułów.
- `workflow.md` — etapowy plan pracy nad aplikacją.
- `ui_guidelines.md` — zasady interfejsu i widoków.

## Rekomendowany kierunek

Budujemy platformę jako pionowy wycinek na module 1:
1. szkielet aplikacji,
2. czytnik modułów,
3. postęp i notatki,
4. tryb ćwiczeń,
5. knowledge check,
6. integracja z agentem.

Nie budujemy od razu pełnego LMS-a.
Najpierw ma powstać małe lokalne narzędzie, które realnie poprawia codzienną naukę.
